📝 ICON PLACEHOLDER

Chrome extension memerlukan icon files:
- icon16.png (16x16 pixels)
- icon48.png (48x48 pixels) 
- icon128.png (128x128 pixels)

Anda dapat membuat icon sendiri atau menggunakan icon generator online.
Recommended: Simple spider atau web scraping themed icon.

Untuk saat ini, extension dapat berjalan tanpa icon (akan menggunakan default Chrome icon).

Alternatif: Anda dapat comment out bagian "icons" di manifest.json jika tidak ingin menggunakan custom icons.
